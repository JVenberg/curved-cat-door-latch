# Cat door latch (curved remix)

A parametric remix of the Printables "Cat Door Latch rev 2" (public domain; originals in `original/`).
It replaces the metal strike plate with a printed **face plate**. A separate **latch arm** follows the door's swing arc and has one slot that holds the door ajar at about 13.9°.

Everything is generated by `cat_door_latch.py` (build123d / OpenCascade). The STEP files import cleanly into Onshape.

## Build

```sh
uv run --with build123d python cat_door_latch.py
uv run --with build123d --with trimesh --with matplotlib --with scipy --with networkx python tools/preview.py
```

The first command writes `out/*.step` and `out/*.stl` and prints the clearance checks. Every overlap must read `0.000`.
The second writes `out/preview.png`. Use bare `python` through `uv`, not `python3`.

| File | What |
|---|---|
| `out/face_plate.stl/.step` | Printed strike plate |
| `out/latch_arm.stl/.step` | Printed arm |
| `out/ref_*.step` | Door (at the slot), lock jamb, casing, for checking fit in CAD |
| `out/hinge_measure.png` | Diagram of how the hinge pivot was measured |
| `cat-door-latch.3mf` | Slicer project |

## Hardware and assembly

- 2x wood screws (the original strike screws) through the plate into the jamb.
- 4x **M3x8 socket head** screws and 4x **standard M3 nuts (2.4 mm thick)**.
  The nuts press into hex pockets in the plate's door-side face. The screws go in from the arm's back, which sits past the trim, so they can be reached after install.

1. Press the nuts into the plate.
2. Screw the plate onto the jamb over the old strike recess.
3. Slide the arm root into the 5 mm reveal between the jamb and the trim.
4. Bolt the arm to the plate. Snug only.

## Printing

- **Plate:** flat on its back, so the nut pockets face up and need no supports.
- **Arm:** standing on its lower edge. It is tall and narrow, so it is prone to lifting:
  - outer brim of 10 to 15 mm, with **brim-object gap = 0** (the default 0.1 let the part tear off the brim);
  - elephant foot compensation 0;
  - glue stick, no part fan for the first layers, no drafts.

See `NOTES.md` for measurements, design reasoning and lessons learned.
